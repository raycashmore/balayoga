# AGENTS.md

Bala Yoga is a Next.js 15 + Payload CMS yoga site.

Package manager: `pnpm`

Non-standard commands:
- `pnpm check` (lint + typecheck)
- `pnpm payload:migrate` (Payload migration files)
- `pnpm db:*` (local Postgres lifecycle)
