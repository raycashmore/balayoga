# Commands

Development:
- `pnpm dev` — start dev server
- `pnpm build` — production build
- `pnpm start` — production server
- `pnpm preview` — build + start production

Code quality:
- `pnpm lint`
- `pnpm lint:fix`
- `pnpm typecheck`
- `pnpm check` — lint + typecheck

Formatting:
- `pnpm format:check`
- `pnpm format:write`

Database (Drizzle ORM):
- `pnpm db:start`
- `pnpm db:generate`
- `pnpm db:migrate`
- `pnpm db:push`
- `pnpm db:studio`

Payload CMS:
- `pnpm payload:types`
- `pnpm payload:importmap`
- `pnpm payload:migrate`
